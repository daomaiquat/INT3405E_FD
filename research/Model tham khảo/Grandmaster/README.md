## 3. Model Architecture (Strictly Conventional ML-Only, Zero LLMs/External OOFs)
1. **Digit-Trie Sparse & Dense GLMs (`02e_SpGLM = 0.949502`, `02f_DeGLM = 0.949881`):** Selective prefix/suffix/cent sparse OHE + 10-knot cubic B-splines (block-scaled L2 logistic `C=0.03`) paired with 3-seed nested empirical-Bayes log-odds TE (`m=[10, 50]`, `C=0.10`).
2. **Strictly Nested-OOF `Blend50` Residual Shallow GBDTs (`03a_OffLGB = 0.950802`, `03b_OffXGB = 0.950816`, `03c_OffCAT = 0.950742`):** Inner 3-fold out-of-fold `Blend50` logits feed 4-leaf `extra_trees` LightGBM, `lossguide 4-leaf max_bin=1024` CUDA XGBoost, and `depth=4 SymmetricTree` GPU CatBoost (3 seeds each).
3. **Standalone High-Bin Shallow GBDT (`03d_StXGB = 0.950247`):** Depth-2 `max_bin=1024` CUDA XGBoost with quantile interaction pairs (`m=20`, 3 seeds).
4. **Zero-TE Cyclic EBM GA2M (`04_EBM = 0.948936`):** `ExplainableBoostingClassifier(max_bins=1024, interactions=25, outer_bags=4)`.
5. **Outer-Fold-Blind `ResDecomp_NonNeg_Logit` Stacker (`logit_eps = 1e-10`):** Explicitly parameterizes residual boosters as $\Delta_m = z_m - z_{\text{b50}}$ under non-negative L2 logistic weights tuned via inner 5-fold CV.

   `jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 notebook.ipynb`

## 6. Known Limitations
- Full 10-fold execution on 699,960 rows requires ~72 min wall clock with CUDA GPU (longer on CPU-only runtimes due to `03b`/`03d` XGBoost & `03c` CatBoost plus 10-fold `EBM`).
- Strictly excludes autoregressive LMs (`GPT-2` / GReaT) and external competitor OOF banks by project governance rules (see `FINAL_RESEARCH_REPORT.md` Section 9).
